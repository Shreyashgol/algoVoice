# 🎙️ AlgoVoice Sample Audio & Voice Generations

This folder stores sample audio outputs generated by the **AlgoVoice Studio** pipeline, demonstrating voice styles, multi-chunk stitching, and AI-directed narrations.

---

### Sample Catalog

| Audio File | Duration | Pipeline / Mode | Description & Voice Persona |
| :--- | :--- | :--- | :--- |
| **`audiobook_ai_voice.wav`** | ~22.5s | Audiobook Producer (AI Directed) | Full document narration with auto-discovered voice persona selected by Groq voice director: *"A calm, authoritative adult voice with a neutral accent..."* |

---

### Audio Specifications
- **Format:** PCM WAV (RIFF Header)
- **Sample Rate:** 24,000 Hz
- **Channels:** 1 (Mono)
- **Bits per Sample:** 16-bit signed integer
- **Chunk Padding:** 0.3s silence frame between stitched segments
